# E-Commerce App

A full-stack E-Commerce web application built using Spring Boot (Backend) and React (Frontend).
The application supports product management, image upload, cart functionality, and search features.

---

## Features
- Add, Update, Delete Products
- Upload Product Images
- Search Products
- Place Orders
- Get order information

---

## Project Structure

Backend
- Controller Layer
- Service Layer
- Repository Layer
- Entity Model

Frontend
- Components
- Context API
- Routing
- Axios API Integration

---

Database

---

## How to Run

Backend
- mvn clean install
- mvn spring-boot:run

Frontend
- npm install
- npm run dev
